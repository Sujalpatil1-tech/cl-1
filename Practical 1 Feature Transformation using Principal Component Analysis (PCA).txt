Practical 1 Feature Transformation using Principal Component Analysis (PCA)

CODE:




# Step 1: Import libraries
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import load_iris
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

# Step 2: Load Iris dataset
iris = load_iris()
X = iris.data
y = iris.target

# Step 3: Standardize the data
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# Step 4: Apply PCA
pca = PCA(n_components=2)
X_pca = pca.fit_transform(X_scaled)

# Step 5: Display dataset dimensions
print("Original Shape:", X.shape)
print("Reduced Shape:", X_pca.shape)

# Step 6: Display explained variance
print("\nExplained Variance Ratio:")
print(pca.explained_variance_ratio_)

print("\nTotal Variance Preserved:")
print(np.sum(pca.explained_variance_ratio_))

# Step 7: Visualize PCA results
plt.figure(figsize=(8, 5))

plt.scatter(X_pca[:, 0], X_pca[:, 1],
            c=y, cmap='viridis')

plt.xlabel("Principal Component 1")
plt.ylabel("Principal Component 2")
plt.title("PCA - Dimensionality Reduction")
plt.colorbar(label="Flower Class")
plt.show()
















1. Aim
To perform feature transformation and dimensionality reduction using Principal Component Analysis (PCA) on a given dataset.


2. Theory
Principal Component Analysis (PCA) is an unsupervised statistical technique used for dimensionality reduction. It transforms a dataset containing a large number of correlated features into a smaller set of new features called principal components while retaining maximum possible information (variance) from the original dataset.

In machine learning, datasets often contain many features, and some features may contain similar or redundant information. This increases computational complexity and makes data analysis difficult. PCA solves this problem by identifying the most important patterns and reducing the number of dimensions.

PCA creates new variables (principal components) that are linear combinations of the original features. These components are arranged in descending order of the amount of variance they explain. The first principal component captures the maximum variance, followed by the second principal component, and so on.


3. Working of PCA

PCA works through the following steps:

1. Data Collection: Load the dataset containing multiple numerical features using Pandas.

2. Data Standardization: Standardize the features using StandardScaler so that all features have a common scale. This prevents features with larger values from dominating the analysis.

3. Covariance Matrix Calculation: Calculate the covariance matrix to understand the relationships and variations between different features.

4. Eigenvalue and Eigenvector Calculation: Calculate eigenvalues and eigenvectors from the covariance matrix. Eigenvalues represent the amount of variance, while eigenvectors represent the directions of the principal components.

5. Principal Component Selection: Select the principal components with the highest eigenvalues because they contain the maximum information from the original dataset.

6. Feature Transformation: Transform the original dataset into a reduced-dimensional dataset using the selected principal components.

7. Visualization: Visualize the transformed data using graphs to understand the reduced dimensions.



4. Important Concepts of PCA
1. Dimensionality Reduction: It is the process of reducing the number of input features while preserving important information.

2. Principal Components: These are new independent variables created by combining the original features. They represent the directions of maximum variance in the dataset.

3. Eigenvalues: Eigenvalues indicate how much variance or information is captured by each principal component.

4. Eigenvectors: Eigenvectors determine the direction of the principal components in the feature space.

5. Explained Variance: It represents the proportion of total information retained by each principal component.

6. Standardization: It converts features into a common scale so that each feature contributes appropriately to PCA.

5. Advantages of PCA
1. Reduces the number of features in a dataset.
2. Removes redundant and highly correlated information.
3. Improves computational efficiency.
4. Helps visualize high-dimensional datasets in 2D or 3D.
5. Reduces the effect of multicollinearity.
6. Can help reduce noise and simplify data analysis.

6. Applications of PCA
1. Image Processing: Used for image compression and reducing image dimensions.
2. Face Recognition: Helps identify important facial features.
3. Medical Data Analysis: Reduces complex medical data into fewer important variables.
4. Data Visualization: Converts high-dimensional data into 2D or 3D representations.
5. Machine Learning: Used as a preprocessing technique before training machine learning models.

7. Libraries Used
- NumPy: Used for numerical calculations.
- Pandas: Used for loading and handling datasets.
- Scikit-learn: Used for standardization and PCA implementation.
- Matplotlib: Used for plotting graphs and visualizing results.

8. Conclusion
Thus, Principal Component Analysis (PCA) was successfully studied and implemented for feature transformation and dimensionality reduction. It converts multiple original features into a smaller number of principal components while retaining maximum possible information. PCA helps simplify datasets, reduce computational complexity and improve data visualization.

Q1. What is PCA?

PCA (Principal Component Analysis) is a dimensionality reduction technique used to reduce the number of features while retaining maximum information.

Q2. What is the main purpose of PCA?

The main purpose of PCA is to reduce dataset dimensions, remove redundant information and simplify data analysis.

Q3. Is PCA supervised or unsupervised?

PCA is an unsupervised learning technique because it does not require labelled output data.

Q4. What is dimensionality reduction?

Dimensionality reduction is the process of reducing the number of features in a dataset while preserving important information.

Q5. What are principal components?

Principal components are new variables formed by combining the original features of a dataset.

Q6. What is the first principal component?

The first principal component is the direction that captures the maximum variance in the dataset.

Q7. What is standardization?

Standardization is the process of converting numerical features into a common scale, generally with mean 0 and standard deviation 1.

Q8. What is a covariance matrix?

A covariance matrix represents the relationship and covariance between different features in a dataset.

Q9. What are eigenvalues?

Eigenvalues represent the amount of variance captured by each principal component.

Q10. What are eigenvectors?

Eigenvectors represent the directions of the principal components in the feature space.

Q11. What is explained variance?

Explained variance indicates the proportion of total dataset variance captured by a principal component.

Q12. Can PCA reduce 10 features into 2 features?

Yes. PCA can transform 10 original features into 2 principal components while retaining as much variance as possible.

Q13. Which Python library is used to implement PCA?

Scikit-learn provides the PCA class in its decomposition module.

Q14. What is the difference between original features and principal components?

Original features are the existing dataset columns, whereas principal components are newly transformed variables created from combinations of original features.

Q15. What are the applications of PCA?

PCA is used in image processing, face recognition, data visualization, medical data analysis and machine learning preprocessing.
