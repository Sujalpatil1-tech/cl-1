CODE:



# Step 1: Import required libraries
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

# Step 2: Create sample Air Quality dataset
data = {
    'Day': ['Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat', 'Sun'],
    'PM2.5': [45, 60, 55, 70, 80, 65, 50],
    'PM10': [80, 95, 90, 110, 120, 100, 85],
    'NO2': [20, 25, 22, 30, 35, 28, 24]
}

df = pd.DataFrame(data)

print("Air Quality Dataset:")
print(df)

# Step 3: Line Plot
plt.figure(figsize=(8, 4))
plt.plot(df['Day'], df['PM2.5'], marker='o',
         label='PM2.5')
plt.plot(df['Day'], df['PM10'], marker='s',
         label='PM10')

plt.title('Air Quality Analysis - Line Plot')
plt.xlabel('Days')
plt.ylabel('Pollution Level')
plt.legend()
plt.grid()
plt.show()

# Step 4: Bar Plot
plt.figure(figsize=(8, 4))
sns.barplot(data=df, x='Day', y='PM2.5')

plt.title('Daily PM2.5 Levels')
plt.xlabel('Days')
plt.ylabel('PM2.5')
plt.show()

# Step 5: Histogram
plt.figure(figsize=(8, 4))
sns.histplot(data=df, x='PM2.5', bins=5, kde=True)

plt.title('Distribution of PM2.5')
plt.xlabel('PM2.5 Level')
plt.ylabel('Frequency')
plt.show()

# Step 6: Scatter Plot
plt.figure(figsize=(8, 4))
sns.scatterplot(data=df, x='PM2.5', y='PM10')

plt.title('PM2.5 vs PM10')
plt.xlabel('PM2.5')
plt.ylabel('PM10')
plt.show()

# Step 7: Heatmap
plt.figure(figsize=(6, 4))
sns.heatmap(df[['PM2.5', 'PM10', 'NO2']].corr(),
            annot=True, cmap='coolwarm')

plt.title('Air Quality Correlation Heatmap')
plt.show()

### **A. Data Visualization**

Data Visualization is the process of representing data in graphical or visual form, such as charts, graphs, and plots, to understand complex information easily.

In an Air Quality dataset, visualization helps us understand pollution levels and identify changes in air quality.

Common air quality parameters include:

- PM2.5 – Fine particulate matter.
- PM10 – Coarse particulate matter.
- NO2 – Nitrogen dioxide.
- SO2 – Sulphur dioxide.
- CO – Carbon monoxide.
- O3 – Ozone.
- AQI – Air Quality Index.

**Example:** We can use a line graph to show how the AQI changes over time or a bar chart to compare pollution levels in different cities.

## **4. Important Concepts**

**1. Figure:** The complete area containing one or more plots.

**2. Axes:** The area where an individual graph is displayed.

**3. X-axis:** Represents independent variables or categories.

**4. Y-axis:** Represents dependent variables or measured values.

**5. Correlation:** Measures the relationship between two numerical variables.

**6. Outlier:** A value that is significantly different from other observations.

**7. Color Map:** Represents numerical values using different colors, especially in heatmaps.

## **5. Difference Between Matplotlib and Seaborn**

| Matplotlib                                 | Seaborn                                         |
| ------------------------------------------ | ----------------------------------------------- |
| Basic Python visualization library.        | Statistical visualization library.              |
| Provides more manual customization.        | Provides attractive default styles.             |
| Suitable for general-purpose graphs.       | Suitable for statistical graphs.                |
| Requires more code for some complex plots. | Often requires less code for statistical plots. |
| Uses `plt` as its common alias.            | Uses `sns` as its common alias.                 |

**Important:** Seaborn is built on top of Matplotlib, so both libraries can be used together.

# **Practical 11: Air Quality Data Visualization using Matplotlib and Seaborn**

## **Step 1: Import required libraries**

```
import pandas as pdimport numpy as npimport matplotlib.pyplot as pltimport seaborn as sns
```

- `pandas`: Used for creating and handling datasets.
- `numpy`: Used for numerical operations.
- `matplotlib.pyplot`: Used to create graphs and visualizations.
- `seaborn`: Used to create attractive statistical graphs.
- `pd`, `np`, `plt`, and `sns` are aliases for these libraries.

## **Step 2: Create sample Air Quality dataset**

```
data = {    'Day': ['Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat', 'Sun'],    'PM2.5': [45, 60, 55, 70, 80, 65, 50],    'PM10': [80, 95, 90, 110, 120, 100, 85],    'NO2': [20, 25, 22, 30, 35, 28, 24]}
```

- `data` is a dictionary containing air quality information for seven days.
- `Day`: Days of the week.
- `PM2.5`: Fine particulate matter concentration.
- `PM10`: Coarse particulate matter concentration.
- `NO2`: Nitrogen dioxide concentration.

```
df = pd.DataFrame(data)print("Air Quality Dataset:")print(df)
```

- `pd.DataFrame(data)` converts the dictionary into a DataFrame.
- `df` stores the dataset.
- `print()` displays the air quality data.

## **Step 3: Line Plot**

```
plt.figure(figsize=(8, 4))
```

- Creates a new figure for the graph.
- `figsize=(8, 4)` sets the width to 8 inches and height to 4 inches.

```
plt.plot(df['Day'], df['PM2.5'], marker='o',         label='PM2.5')
```

- `plt.plot()` creates a line graph.
- `df['Day']` represents the X-axis.
- `df['PM2.5']` represents the Y-axis.
- `marker='o'` displays circular markers at each data point.
- `label='PM2.5'` assigns a legend name to the line.

```
plt.plot(df['Day'], df['PM10'], marker='s',         label='PM10')
```

- Creates another line on the same graph.
- `df['PM10']` provides the PM10 values.
- `marker='s'` displays square markers.
- `label='PM10'` identifies this line in the legend.

```
plt.title('Air Quality Analysis - Line Plot')plt.xlabel('Days')plt.ylabel('Pollution Level')plt.legend()plt.grid()plt.show()
```

- `title()` sets the graph title.
- `xlabel()` sets the horizontal axis label.
- `ylabel()` sets the vertical axis label.
- `legend()` displays the names of both lines.
- `grid()` displays grid lines.
- `show()` displays the graph.

**Graph interpretation:**

- X-axis represents the days of the week.
- Y-axis represents pollution levels.
- Two lines compare PM2.5 and PM10 levels.
- PM10 values are higher than PM2.5 values throughout the week.

## **Step 4: Bar Plot**

```
plt.figure(figsize=(8, 4))sns.barplot(data=df, x='Day', y='PM2.5')
```

- `plt.figure()` creates a new graph.
- `figsize=(8, 4)` defines the graph size.
- `sns.barplot()` creates a bar chart using Seaborn.
- `data=df` specifies the dataset.
- `x='Day'` sets the X-axis.
- `y='PM2.5'` sets the Y-axis.

```
plt.title('Daily PM2.5 Levels')plt.xlabel('Days')plt.ylabel('PM2.5')plt.show()
```

- Sets the graph title.
- Sets the X-axis and Y-axis labels.
- `show()` displays the bar chart.

**Graph interpretation:**

- Each bar represents the PM2.5 level for one day.
- The height of the bar represents the pollution level.
- Friday has the highest PM2.5 level (80).
- Monday has the lowest PM2.5 level (45).

## **Step 5: Histogram**

```
plt.figure(figsize=(8, 4))sns.histplot(data=df, x='PM2.5', bins=5, kde=True)
```

- `plt.figure()` creates a new figure.
- `sns.histplot()` creates a histogram.
- `data=df` specifies the dataset.
- `x='PM2.5'` selects the PM2.5 column.
- `bins=5` divides the PM2.5 values into five intervals.
- `kde=True` displays a smooth density curve over the histogram.

```
plt.title('Distribution of PM2.5')plt.xlabel('PM2.5 Level')plt.ylabel('Frequency')plt.show()
```

- Sets the graph title.
- X-axis represents PM2.5 values.
- Y-axis represents frequency (number of observations).
- Displays the histogram.

**Graph interpretation:**

- Shows the distribution of PM2.5 values.
- Each bar represents the number of observations within an interval.
- The KDE curve helps visualize the overall distribution pattern.

## **Step 6: Scatter Plot**

```
plt.figure(figsize=(8, 4))sns.scatterplot(data=df, x='PM2.5', y='PM10')
```

- `plt.figure()` creates a new figure.
- `sns.scatterplot()` creates a scatter plot.
- `data=df` specifies the dataset.
- `x='PM2.5'` represents the X-axis.
- `y='PM10'` represents the Y-axis.
- Each dot represents one day's air quality measurements.

```
plt.title('PM2.5 vs PM10')plt.xlabel('PM2.5')plt.ylabel('PM10')plt.show()
```

- Sets the graph title.
- Sets the X-axis and Y-axis labels.
- Displays the scatter plot.

**Graph interpretation:**

- Each point represents the relationship between PM2.5 and PM10.
- The points show an overall positive relationship: higher PM2.5 values generally correspond to higher PM10 values.

## **Step 7: Heatmap**

```
plt.figure(figsize=(6, 4))
```

- Creates a new figure.
- Sets the graph width to 6 inches and height to 4 inches.

```
sns.heatmap(df[['PM2.5', 'PM10', 'NO2']].corr(),            annot=True, cmap='coolwarm')
```

- `sns.heatmap()` creates a correlation heatmap.
- `df[['PM2.5', 'PM10', 'NO2']]` selects the three numerical columns.
- `.corr()` calculates the correlation between these columns.
- `annot=True` displays correlation values inside the cells.
- `cmap='coolwarm'` applies a colour scheme to represent correlation values.

**Understanding correlation:**

- `+1`: Perfect positive correlation.
- `0`: No linear correlation.
- `-1`: Perfect negative correlation.

```
plt.title('Air Quality Correlation Heatmap')plt.show()
```

- `title()` sets the heatmap title.
- `show()` displays the final heatmap.

**Graph interpretation:**

- The heatmap shows correlations between PM2.5, PM10 and NO2.
- Values closer to +1 indicate a stronger positive linear relationship.
- Values closer to -1 indicate a stronger negative linear relationship.
- The diagonal values are always 1 because each variable is perfectly correlated with itself.
