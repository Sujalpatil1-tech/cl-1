# Step 1: Import required libraries
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# Step 2: Create sample sales dataset
data = {
    'Order_ID': [101, 102, 103, 104, 105, 106, 107, 108],
    'Product': ['Laptop', 'Mobile', 'Laptop', 'Tablet',
                'Mobile', 'Tablet', 'Laptop', 'Mobile'],
    'Region': ['North', 'South', 'East', 'West',
               'North', 'South', 'West', 'East'],
    'Quantity': [2, 3, 1, 4, 2, 3, 2, 1],
    'Sales': [100000, 45000, 50000, 80000,
              30000, 60000, 120000, 15000]
}

df = pd.DataFrame(data)

print("Original Sales Dataset:")
print(df)

# Step 3: Total Sales
total_sales = df['Sales'].sum()

print("\nTotal Sales:", total_sales)

# Step 4: Sales by Product
product_sales = df.groupby('Product')['Sales'].sum()

print("\nSales by Product:")
print(product_sales)

# Step 5: Sales by Region
region_sales = df.groupby('Region')['Sales'].sum()

print("\nSales by Region:")
print(region_sales)

# Step 6: Aggregate Sales and Quantity
summary = df.groupby('Product').agg({
    'Sales': ['sum', 'mean', 'max'],
    'Quantity': 'sum'
})

print("\nProduct Sales Summary:")
print(summary)

# Step 7: Create Pivot Table
pivot = pd.pivot_table(
    df,
    values='Sales',
    index='Product',
    columns='Region',
    aggfunc='sum',
    fill_value=0
)

print("\nSales Pivot Table:")
print(pivot)

# Step 8: Find Best Selling Product
best_product = product_sales.idxmax()

print("\nBest Selling Product:", best_product)

# Step 9: Find Highest Sales Region
best_region = region_sales.idxmax()

print("Highest Sales Region:", best_region)

# Step 10: Display final dataset information
print("\nDataset Information:")
print(df.info())

# Step 11: Visualize Sales by Region (Bar Chart) and Product (Pie Chart)
plt.figure(figsize=(10, 4))

# Bar Plot for Region Sales
plt.subplot(1, 2, 1)
region_sales.plot(kind='bar', color='skyblue', edgecolor='black')
plt.title('Total Sales by Region')
plt.xlabel('Region')
plt.ylabel('Sales')
plt.xticks(rotation=0)

# Pie Chart for Product Sales Share
plt.subplot(1, 2, 2)
product_sales.plot(kind='pie', autopct='%1.1f%%', startangle=90)
plt.title('Sales Share by Product')
plt.ylabel('')  # Hides default y-axis label

plt.tight_layout()
plt.show()






















# **Practical 12: Data Aggregation and Sales Performance Analysis**

## **1. Aim**

To perform data aggregation and sales performance analysis using Python and Pandas to summarize sales data, calculate important business metrics, and identify sales trends and patterns.

## **2. Theory**

### **A. Data Aggregation**

Data Aggregation is the process of collecting, grouping, and summarizing large amounts of data to obtain meaningful information.

It helps convert detailed records into summarized information for analysis and decision-making.

**Example:** A company has thousands of sales transactions. Instead of checking every transaction individually, it can calculate:

- Total sales of the company.
- Total sales of each product.
- Sales generated by each region.
- Average sales per transaction.
- Total quantity of products sold.

### **B. Sales Performance Analysis**

Sales Performance Analysis is the process of evaluating sales data to understand how well a business, product, employee, or region is performing.

A sales dataset may contain:

| Column     | Description           |
| ---------- | --------------------- |
| Order ID   | Unique order number.  |
| Product    | Name of the product.  |
| Category   | Product category.     |
| Quantity   | Number of units sold. |
| Unit Price | Price of one product. |
| Sales      | Total sales amount.   |
| Region     | Sales location.       |
| Date       | Date of transaction.  |

**Example:** A company wants to identify which product generates the highest revenue and which region has the highest sales.

Data aggregation helps answer these questions.

### **C. GroupBy Operation**

GroupBy is a Pandas operation used to divide data into groups based on one or more columns and perform calculations on each group.

It follows three important steps:

**1. Split**

Divide data into groups based on a column.

**2. Apply**

Perform calculations on each group.

**3. Combine**

Combine the results into a summarized output.

Example:

Original sales data:

| Product | Sales |
| ------- | ----- |
| Laptop  | 50000 |
| Mobile  | 20000 |
| Laptop  | 30000 |
| Mobile  | 15000 |

After grouping by Product and calculating total sales:

| Product | Total Sales |
| ------- | ----------- |
| Laptop  | 80000       |
| Mobile  | 35000       |

Here, `groupby()` groups similar products, and `sum()` calculates their total sales.

### **D. Aggregation Functions**

Aggregation functions are used to calculate summary values from grouped data.

| Function   | Purpose                        | Example            |
| ---------- | ------------------------------ | ------------------ |
| `sum()`    | Calculates total.              | Total sales        |
| `mean()`   | Calculates average.            | Average sales      |
| `count()`  | Counts records.                | Number of orders   |
| `min()`    | Finds minimum value.           | Lowest sales       |
| `max()`    | Finds maximum value.           | Highest sales      |
| `median()` | Finds middle value.            | Median order value |
| `std()`    | Calculates standard deviation. | Variation in sales |

### **E. Pivot Table**

A Pivot Table is a data summarization tool used to arrange and summarize data based on rows and columns.

It helps compare multiple categories easily.

Example:

| Region | Laptop | Mobile |
| ------ | ------ | ------ |
| Pune   | 80000  | 35000  |
| Nashik | 60000  | 25000  |

This table helps compare product sales across different regions.

In Pandas, `pivot_table()` is used to create pivot tables.

### **F. Important Sales Performance Metrics**

1\. **Total Revenue:** Total money generated through sales.

\\[ \text{Revenue}=\sum(\text{Quantity}\times\text{Unit Price}) \\]

2\. **Total Quantity Sold:** Total number of units sold.

\\[ \text{Total Quantity}=\sum \text{Quantity} \\]

3\. **Average Sales:** Average sales value per transaction.

\\[ \text{Average Sales}=\frac{\text{Total Sales}}{\text{Number of Transactions}} \\]

4\. **Highest Sales:** Maximum sales value generated.

5\. **Regional Sales:** Total revenue generated by each geographical region.

## **Step 6: Aggregate Sales and Quantity**

```
summary = df.groupby('Product').agg({    'Sales': ['sum', 'mean', 'max'],    'Quantity': 'sum'})
```

This statement performs multiple calculations on grouped data.

- `groupby('Product')` groups records by product.
- `.agg()` means aggregation. It applies multiple functions to columns.
- `'Sales': ['sum', 'mean', 'max']` performs three calculations:
  - `sum` – Total sales of the product.
  - `mean` – Average sales of the product.
  - `max` – Maximum sales in a single order.
- `'Quantity': 'sum'` calculates the total quantity sold for each product.
- `summary` stores the aggregated result.

```
print("\nProduct Sales Summary:")print(summary)
```

| Mobile  | 90000     | 30000      | 45000     | 6            |
| Tablet  | 140000    | 70000      | 80000     | 7            |

**Important:** `agg()` allows us to apply multiple statistical functions to grouped data at the same time.

## **Step 7: Create Pivot Table**

```
pivot = pd.pivot_table(    df,    values='Sales',    index='Product',    columns='Region',    aggfunc='sum',    fill_value=0)
```

A pivot table summarizes data by arranging it into rows and columns.

- `pd.pivot_table()` creates a pivot table.
- `df` – Source dataset.
- `values='Sales'` – Uses the Sales column for calculations.
- `index='Product'` – Displays products as rows.
- `columns='Region'` – Displays regions as columns.
- `aggfunc='sum'` – Calculates the sum of sales for each product-region combination.
- `fill_value=0` – Replaces missing combinations with zero.
- `pivot` stores the resulting pivot table.

```
print("\nSales Pivot Table:")print(pivot)
```

**Expected output:**

| Product | East  | North  | South | West   |
| ------- | ----- | ------ | ----- | ------ |
| Laptop  | 50000 | 100000 | 0     | 120000 |
| Mobile  | 15000 | 30000  | 45000 | 0      |

**Important:** A pivot table helps compare sales across multiple categories, such as products and regions.
