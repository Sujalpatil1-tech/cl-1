Practical 4 Clustering Analysis using K-Means with Elbow Method

CODE:


# Step 1: Import required libraries
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

# Step 2: Create sample dataset
data = {
    'Annual Income': [15, 16, 17, 18, 20, 50, 52, 55,
                      58, 60, 85, 88, 90, 92, 95],
    'Spending Score': [80, 85, 78, 82, 88, 40, 45, 42,
                       38, 35, 20, 25, 18, 22, 15]
}

df = pd.DataFrame(data)

# Step 3: Select features
X = df[['Annual Income', 'Spending Score']]

# Step 4: Standardize the data
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# Step 5: Calculate WCSS using Elbow Method
wcss = []

for i in range(1, 6):
    kmeans = KMeans(n_clusters=i, random_state=42, n_init=10)
    kmeans.fit(X_scaled)
    wcss.append(kmeans.inertia_)

# Step 6: Plot Elbow graph
plt.figure(figsize=(7, 5))
plt.plot(range(1, 6), wcss, marker='o')

plt.xlabel("Number of Clusters (K)")
plt.ylabel("WCSS")
plt.title("Elbow Method")
plt.show()

# Step 7: Apply K-Means clustering
kmeans = KMeans(n_clusters=3, random_state=42, n_init=10)
df['Cluster'] = kmeans.fit_predict(X_scaled)

# Step 8: Display clustered dataset
print("\nClustered Dataset:")
print(df)

# Step 9: Visualize clusters
plt.figure(figsize=(7, 5))

plt.scatter(
    X_scaled[:, 0],
    X_scaled[:, 1],
    c=df['Cluster'],
    cmap='viridis'
)

plt.xlabel("Annual Income (Standardized)")
plt.ylabel("Spending Score (Standardized)")
plt.title("K-Means Clustering")
plt.show()








# **Practical 4: Clustering Analysis Using K-Means with Elbow Method**

## **1. Aim**

To perform clustering analysis on a given dataset using the K-Means clustering algorithm and determine the optimal number of clusters using the Elbow Method.

## **2. Theory**

**Clustering** is an unsupervised machine learning technique used to group similar data points into clusters based on their characteristics or similarities.

In clustering, the dataset does not contain predefined class labels. The algorithm automatically identifies patterns and groups similar observations together.

**K-Means Clustering** is an unsupervised machine learning algorithm that divides a dataset into K clusters. Each cluster is represented by a center point called a centroid.

The main objective of K-Means is to group similar data points together while minimizing the distance between data points and their respective cluster centroids.

### **Working of K-Means Algorithm**

1. **Choose K:** Select the required number of clusters.
2. **Initialize Centroids:** Randomly select K initial centroid positions.
3. **Assign Data Points:** Assign each data point to its nearest centroid using distance calculation.
4. **Update Centroids:** Calculate the mean of all data points in each cluster to obtain new centroid positions.
5. **Repeat:** Repeat the assignment and centroid update steps until the centroids stop changing significantly or the algorithm reaches its stopping condition.
6. **Final Clusters:** Obtain the final groups of similar data points.

### **K-Means Objective Function**

K-Means tries to minimize the Within-Cluster Sum of Squares (WCSS).

\\[ WCSS=\sum\_{j=1}^{K}\sum\_{x_i\in C_j} \\|x_i-\mu_j\\|^2 \\]

Where:

- K = Number of clusters
- \\(C_j\\) = Cluster j
- \\(x_i\\) = Data point
- \\(\mu_j\\) = Centroid of cluster j

Lower WCSS indicates that data points are closer to their respective centroids.

### **Elbow Method**

The **Elbow Method** is used to find the optimal number of clusters (K) in K-Means clustering.

It calculates WCSS for different values of K and plots a graph between the number of clusters and WCSS.

[ceve543.github.io](https://ceve543.github.io/lectures/2025-10-27/index.html?utm_source=chatgpt.com)

**Working of Elbow Method:**

1. Apply K-Means with different values of K, such as 1 to 10.
2. Calculate WCSS for each value of K.
3. Plot K on the X-axis and WCSS on the Y-axis.
4. Observe the graph.
5. Select the point where the decrease in WCSS starts becoming slower. This point is called the elbow point.

**Example:** If the graph shows a clear elbow at K = 3, then three clusters may be selected as the optimal number.

The Elbow Method provides a useful estimate; sometimes the graph does not have a clear elbow.

**Q4. What does K represent in K-Means?**

K represents the number of clusters to be created.

**Q5. What is a Centroid?**

A centroid is the center point of a cluster, calculated as the mean of the data points belonging to that cluster.

**Q6. What is the main objective of K-Means?**

To minimize the within-cluster sum of squared distances between data points and their respective centroids.

**Q7. What is WCSS?**

Within-Cluster Sum of Squares measures the sum of squared distances between data points and their cluster centroids.

**Q8. What is the Elbow Method?**

It is a technique used to estimate the optimal number of clusters by plotting WCSS against different K values.

**Q9. Why is it called the Elbow Method?**

Because the graph often forms a bend resembling an elbow at the point where adding more clusters gives smaller improvements.

**Q13. Can K-Means work without labelled data?**

Yes. K-Means does not require predefined class labels.

Inertia is the sum of squared distances between each data point and its nearest cluster centroid. It is equivalent to WCSS.
