# Step 1: Import libraries
import numpy as np
import random

# Step 2: Initialize Q-table
Q = {}

alpha = 0.1
gamma = 0.9
epsilon = 0.1

# Step 3: Check winning condition
def check_winner(board, player):
    win_positions = [
        (0, 1, 2), (3, 4, 5), (6, 7, 8),
        (0, 3, 6), (1, 4, 7), (2, 5, 8),
        (0, 4, 8), (2, 4, 6)
    ]

    for a, b, c in win_positions:
        if board[a] == board[b] == board[c] == player:
            return True

    return False

# Step 4: Get available actions
def available_actions(board):
    return [i for i in range(9) if board[i] == ' ']

# Step 5: Get Q-values for a state
def get_q(state):
    if state not in Q:
        Q[state] = np.zeros(9)
    return Q[state]

# Step 6: Select action using epsilon-greedy policy
def choose_action(board, training=False):
    state = ''.join(board)
    actions = available_actions(board)

    if training and random.random() < epsilon:
        return random.choice(actions)

    q_values = get_q(state)
    return max(actions, key=lambda a: q_values[a])

# Step 7: Train the Q-learning agent
for episode in range(20000):

    board = [' '] * 9

    while True:
        state = ''.join(board)

        # Agent X selects a move
        action = choose_action(board, training=True)
        board[action] = 'X'

        # Check if X wins
        if check_winner(board, 'X'):
            reward = 1
            done = True

        elif not available_actions(board):
            reward = 0
            done = True

        else:
            done = False
            reward = 0

            # Random opponent O makes a move
            opponent_action = random.choice(available_actions(board))
            board[opponent_action] = 'O'

            # Check if O wins
            if check_winner(board, 'O'):
                reward = -1
                done = True

            elif not available_actions(board):
                reward = 0
                done = True

        # Step 8: Update Q-value
        if done:
            target = reward
        else:
            next_state = ''.join(board)
            next_actions = available_actions(board)
            target = reward + gamma * max(
                get_q(next_state)[a] for a in next_actions
            )

        Q[state][action] += alpha * (target - Q[state][action])

        if done:
            break

print("Training completed!")
print("Total training games: 20000")

# Step 9: Display game board
def display_board(board):
    print()
    for i in range(0, 9, 3):
        print(" | ".join(
            board[j] if board[j] != ' ' else str(j + 1)
            for j in range(i, i + 3)
        ))
        if i < 6:
            print("---------")
    print()

# Step 10: Play against the trained agent
board = [' '] * 9

print("\nYou are O. Computer is X.")
print("Enter positions from 1 to 9.")

while True:

    # Computer move
    action = choose_action(board)
    board[action] = 'X'

    print("\nComputer's move:")
    display_board(board)

    if check_winner(board, 'X'):
        print("Computer wins!")
        break

    if not available_actions(board):
        print("Game Draw!")
        break

    # Human move
    while True:
        try:
            move = int(input("Enter your move (1-9): ")) - 1

            if move in available_actions(board):
                board[move] = 'O'
                break
            else:
                print("Invalid position! Try again.")

        except ValueError:
            print("Please enter a number from 1 to 9.")

    display_board(board)

    if check_winner(board, 'O'):
        print("You win!")
        break

    if not available_actions(board):
        print("Game Draw!")
        break

## **2. Theory**

**Reinforcement Learning (RL)** is a type of machine learning in which an agent learns to make decisions by interacting with an environment and receiving rewards or penalties for its actions.

The main objective of Reinforcement Learning is to learn the best actions that maximize the total cumulative reward over time.

In this practical, the Q-Learning algorithm is used to train an agent to play Tic-Tac-Toe. The agent learns by playing the game, observing the results of its moves and improving its decisions through repeated experiences.

### **Important Components of Reinforcement Learning**

1. **Agent:** The learner or decision-maker. In this practical, the agent is the Tic-Tac-Toe player being trained.
2. **Environment:** The surroundings in which the agent operates. Here, it is the Tic-Tac-Toe game.
3. **State:** The current situation of the environment. Here, it represents the current arrangement of X and O on the board.
4. **Action:** A decision taken by the agent. Here, selecting an empty cell to place its symbol.
5. **Reward:** Feedback received after performing an action. Winning may give a positive reward, while losing may give a negative reward.
6. **Policy:** A strategy followed by the agent to select actions.
7. **Q-Value:** The expected future reward for taking a particular action in a particular state.

### **What is Q-Learning?**

**Q-Learning** is a model-free, value-based Reinforcement Learning algorithm that learns the best action to take in a particular state by updating Q-values based on rewards and future expected rewards.

It uses a Q-Table to store the estimated value of state-action pairs.

### **Q-Learning Formula**

\\[ Q(s,a)\leftarrow Q(s,a)+ \alpha[r+\gamma\max\_{a'}Q(s',a')-Q(s,a)] \\]

Where:

- \\(Q(s,a)\\) = Current Q-value
- \\(s\\) = Current state
- \\(a\\) = Current action
- \\(\alpha\\) = Learning rate
- \\(r\\) = Immediate reward
- \\(\gamma\\) = Discount factor
- \\(s'\\) = Next state
- \\(\max Q(s',a')\\) = Maximum expected future Q-value

### **Explanation of Q-Learning Parameters**

| Parameter           | Meaning                                               |
| ------------------- | ----------------------------------------------------- |
| Learning Rate (α)   | Controls how much new information updates the Q-value |
| Discount Factor (γ) | Determines the importance of future rewards           |
| Reward (r)          | Feedback received after an action                     |
| Q-Value             | Estimated value of an action in a state               |
| Exploration         | Trying different actions to learn                     |
| Exploitation        | Choosing the best-known action                        |
