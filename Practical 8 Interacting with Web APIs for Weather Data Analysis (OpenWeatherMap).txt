# Step 1: Import required libraries
import requests
import pandas as pd

# Step 2: Enter API key and city name
API_KEY = "YOUR_API_KEY"
CITY = "Nashik"

# Step 3: Define API URL
url = "https://api.openweathermap.org/data/2.5/weather"

# Step 4: Define request parameters
params = {
    "q": CITY,
    "appid": API_KEY,
    "units": "metric"
}

# Step 5: Send GET request
response = requests.get(url, params=params)

# Step 6: Check API response
if response.status_code == 200:

    # Convert JSON response into Python dictionary
    data = response.json()

    # Step 7: Extract weather information
    weather_data = {
        "City": data["name"],
        "Temperature": data["main"]["temp"],
        "Humidity": data["main"]["humidity"],
        "Pressure": data["main"]["pressure"],
        "Weather": data["weather"][0]["description"],
        "Wind Speed": data["wind"]["speed"]
    }

    # Step 8: Create DataFrame
    df = pd.DataFrame([weather_data])

    # Step 9: Display weather information
    print("Current Weather Information:")
    print(df)

else:
    print("Error:", response.status_code)
    print(response.json())

### **HTTP Methods**

- **POST:** Sends data to a server.
- **PUT:** Updates existing data.
- **DELETE:** Deletes data.

In this practical, the GET method is commonly used to retrieve weather information.

An API key is a unique authentication code used to identify and authorize an application when accessing an API.

OpenWeatherMap requires an API key for accessing its weather services.

# **Practical 8: Weather Data Analysis using OpenWeatherMap API and Pandas**

## **Step 1: Import required libraries**

```
import requestsimport pandas as pd
```

- `requests`: Python library used to send HTTP requests and access data from APIs.
- `pandas`: Used to organize and display the retrieved data in tabular format.
- `pd`: Alias for Pandas.

## **Step 2: Enter API key and city name**

```
API_KEY = "YOUR_API_KEY"CITY = "Nashik"
```

- `API_KEY` stores the API key obtained from OpenWeatherMap.
- `"YOUR_API_KEY"` is a placeholder. Replace it with your actual API key.
- `CITY` stores the name of the city for which weather information is required.
- Here, the city is Nashik.

## **Step 3: Define API URL**

```
url = "https://api.openweathermap.org/data/2.5/weather"
```

- `url` stores the API endpoint.
- An API endpoint is a URL through which an application requests data from a server.
- This endpoint provides current weather information.

## **Step 4: Define request parameters**

```
params = {    "q": CITY,    "appid": API_KEY,    "units": "metric"}
```

- `params` is a dictionary containing the parameters required by the API.
- `"q": CITY` specifies the city name.
- `"appid": API_KEY` provides the API authentication key.
- `"units": "metric"` requests temperature in Celsius and wind speed in metres per second.

## **Step 5: Send GET request**

```
response = requests.get(url, params=params)
```

- `requests.get()` sends an HTTP GET request to the API.
- `url` specifies the API endpoint.
- `params=params` sends the city name, API key and measurement units.
- `response` stores the server's response.

## **Step 6: Check API response**

```
if response.status_code == 200:
```

- `status_code` represents the HTTP response status.
- `200` means the request was successful.
- `if` checks whether the API returned a successful response.

**Convert JSON response into Python dictionary**

```
data = response.json()
```

- `response.json()` converts the JSON response received from the API into a Python dictionary.
- `data` stores the complete weather information.

## **Step 7: Extract weather information**

```
weather_data = {    "City": data["name"],    "Temperature": data["main"]["temp"],    "Humidity": data["main"]["humidity"],    "Pressure": data["main"]["pressure"],    "Weather": data["weather"][0]["description"],    "Wind Speed": data["wind"]["speed"]}
```

This dictionary extracts the required weather information from the API response.

- `"City": data["name"]` extracts the city name.
- `"Temperature": data["main"]["temp"]` extracts the current temperature in Celsius.
- `"Humidity": data["main"]["humidity"]` extracts humidity in percentage.
- `"Pressure": data["main"]["pressure"]` extracts atmospheric pressure in hPa.
- `"Weather": data["weather"][0]["description"]` extracts the weather description, such as clear sky or light rain.
- `"Wind Speed": data["wind"]["speed"]` extracts wind speed in metres per second.

**Important:** `data["main"]`, `data["weather"]` and `data["wind"]` are nested dictionaries/lists in the API response.

## **Step 8: Create DataFrame**

```
df = pd.DataFrame([weather_data])
```

- `pd.DataFrame()` converts the weather dictionary into a Pandas DataFrame.
- `[weather_data]` places the dictionary inside a list to create one row.
- `df` stores the resulting table.

## **Step 9: Display weather information**

```
print("Current Weather Information:")print(df)
```

- The first `print()` displays the heading.
- The second `print()` displays the weather information in tabular format.

**If API request fails:**

```
else:    print("Error:", response.status_code)    print(response.json())
```

- `else` executes when the response status code is not 200.
- `response.status_code` displays the error status code.
- `response.json()` displays the error details returned by the API.

**Example:** Status code `401` generally indicates an invalid or missing API key.

**Practical note:** Before running the program, replace `YOUR_API_KEY` with a valid OpenWeatherMap API key. You also need the `requests` and `pandas` libraries installed.
