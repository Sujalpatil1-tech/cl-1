CODE:




# Step 1: Import required libraries
import pandas as pd
import numpy as np

# Step 2: Create a sample telecom dataset
data = {
    'CustomerID': [101, 102, 103, 104, 104, 105],
    'Gender': ['Male', 'Female', 'Male', 'Female', 'Female', 'Male'],
    'Tenure': [12, 24, np.nan, 36, 36, 18],
    'MonthlyCharges': [50.5, 60.0, 70.5, np.nan, np.nan, 45.0],
    'TotalCharges': ['606', '1440', ' ', ' ', ' ', '810'],
    'Contract': ['Month-to-month', 'One year', 'Two year',
                 'Month-to-month', 'Month-to-month', 'One year'],
    'Churn': ['Yes', 'No', 'Yes', 'No', 'No', 'Yes']
}

df = pd.DataFrame(data)

print("Original Dataset:")
print(df)

# Step 3: Check dataset information
print("\nDataset Information:")
print(df.info())

# Step 4: Check missing values
print("\nMissing Values:")
print(df.isnull().sum())

# Step 5: Replace blank spaces with NaN
df['TotalCharges'] = df['TotalCharges'].replace(' ', np.nan)

# Step 6: Convert TotalCharges into numeric format
df['TotalCharges'] = pd.to_numeric(
    df['TotalCharges'], errors='coerce'
)

# Step 7: Remove duplicate records
df = df.drop_duplicates()

# Step 8: Fill missing numerical values with median
df['Tenure'] = df['Tenure'].fillna(df['Tenure'].median())
df['MonthlyCharges'] = df['MonthlyCharges'].fillna(
    df['MonthlyCharges'].median()
)
df['TotalCharges'] = df['TotalCharges'].fillna(
    df['TotalCharges'].median()
)

# Step 9: Fill missing categorical values with mode
df['Gender'] = df['Gender'].fillna(df['Gender'].mode()[0])

# Step 10: Convert categorical columns into numerical values
df['Gender'] = df['Gender'].map({'Male': 1, 'Female': 0})
df['Churn'] = df['Churn'].map({'Yes': 1, 'No': 0})

# Step 11: Display cleaned dataset
print("\nCleaned Dataset:")
print(df)

# Step 12: Check missing values after cleaning
print("\nMissing Values After Cleaning:")
print(df.isnull().sum())

# Step 13: Display final dataset information
print("\nFinal Dataset Information:")
print(df.info())

### **What is Telecom Churn?**

Telecom Churn refers to the situation in which a customer stops using the services of a telecom company or switches to another service provider.

**Example:**

Suppose a telecom company has 1,000 customers. If 100 customers discontinue their services, those 100 customers are called churned customers.

The churn rate is:

\\[ Churn\ Rate=\frac{Number\ of\ Churned\ Customers}{Total\ Customers}\times100 \\]

For this example:

\\[ Churn\ Rate=\frac{100}{1000}\times100=10\\% \\]

Raw telecom datasets may contain the following problems:

1. **Missing Values:** Some records may have empty or null values.
2. **Duplicate Records:** The same customer information may appear multiple times.
3. **Incorrect Data Types:** Numerical values may be stored as text.

### **Important Data Cleaning Techniques**

**A. Handling Missing Values**

Missing values occur when some information is not available in the dataset.

Methods:

- Remove rows containing missing values using `dropna()`.
- Fill missing values using `fillna()`.
- Replace missing numerical values with mean or median.
- Replace missing categorical values with mode.

**B. Removing Duplicate Records**

Duplicate records are repeated entries in a dataset.

Pandas functions:

- `duplicated()` – Identifies duplicate records.
- `drop_duplicates()` – Removes duplicate records.

**C. Handling Incorrect Data Types**

Sometimes numerical columns are stored as strings or objects.

Example: Monthly charges stored as text instead of numerical values.

Pandas function:

- `astype()` – Converts data types.
- `pd.to_numeric()` – Converts values into numeric format.

**D. Handling Outliers**

Outliers are observations that are significantly different from other values in the dataset.

They can be detected using:

- Box plots
- Interquartile Range (IQR)
- Statistical methods

The IQR method uses:

\\[ IQR=Q3-Q1 \\]

Where:

- Q1 = First quartile
- Q3 = Third quartile

Common lower and upper limits are:

\\[ Lower=Q1-1.5(IQR) \\]

\\[ Upper=Q3+1.5(IQR) \\]

Outliers should be investigated before removing them because they may represent genuine customer behavior.

**E. Encoding Categorical Data**

Machine learning algorithms often require numerical input. Therefore, categorical values are converted into numerical representations.

Example:

| Gender | Encoded Value |
| ------ | ------------- |
| Male   | 0             |
| Female | 1             |

Common methods:

- Label Encoding
- One-Hot Encoding

# **Practical 9: Data Cleaning and Preprocessing using Pandas**

## **Step 1: Import required libraries**

```
import pandas as pdimport numpy as np
```

- `pandas`: Used for data manipulation, cleaning and analysis.
- `numpy`: Used for numerical operations and handling missing values.
- `pd` and `np` are aliases for Pandas and NumPy.

## **Step 2: Create a sample telecom dataset**

```
data = {    'CustomerID': [101, 102, 103, 104, 104, 105],    'Gender': ['Male', 'Female', 'Male', 'Female', 'Female', 'Male'],    'Tenure': [12, 24, np.nan, 36, 36, 18],    'MonthlyCharges': [50.5, 60.0, 70.5, np.nan, np.nan, 45.0],    'TotalCharges': ['606', '1440', ' ', ' ', ' ', '810'],    'Contract': ['Month-to-month', 'One year', 'Two year',                 'Month-to-month', 'Month-to-month', 'One year'],    'Churn': ['Yes', 'No', 'Yes', 'No', 'No', 'Yes']}
```

- `data` is a Python dictionary containing telecom customer information.
- `CustomerID`: Unique identification number of each customer.
- `Gender`: Gender of the customer.
- `Tenure`: Number of months the customer has used the service.
- `MonthlyCharges`: Monthly amount paid by the customer.
- `TotalCharges`: Total amount paid by the customer.
- `Contract`: Type of contract selected by the customer.
- `Churn`: Indicates whether the customer has left the service.
- `np.nan` represents a missing numerical value.
- `' '` represents a blank string, which is different from a missing value (`NaN`).

```
df = pd.DataFrame(data)print("Original Dataset:")print(df)
```

- `pd.DataFrame(data)` converts the dictionary into a DataFrame.
- `df` stores the original dataset.
- `print()` displays the dataset.

## **Step 3: Check dataset information**

```
print("\nDataset Information:")print(df.info())
```

- `df.info()` displays the structure of the dataset.
- It shows the number of rows and columns.
- It displays column names, non-null values, data types and memory usage.
- This helps identify missing values and incorrect data types.

**Note:** `df.info()` already displays the information and returns `None`. Therefore, use `df.info()` directly instead of `print(df.info())` to avoid displaying `None`.

## **Step 4: Check missing values**

```
print("\nMissing Values:")print(df.isnull().sum())
```

- `df.isnull()` checks every cell for missing values.
- It returns `True` for missing values and `False` for available values.
- `.sum()` counts the missing values in each column.
- `print()` displays the missing-value count.

## **Step 5: Replace blank spaces with NaN**

```
df['TotalCharges'] = df['TotalCharges'].replace(' ', np.nan)
```

- `df['TotalCharges']` selects the TotalCharges column.
- `.replace()` replaces specified values with new values.
- `' '` represents a blank string.
- `np.nan` represents a missing value.
- The cleaned column is assigned back to `df['TotalCharges']`.

This step converts blank strings into proper missing values so Pandas can identify and handle them.

## **Step 6: Convert TotalCharges into numeric format**

```
df['TotalCharges'] = pd.to_numeric(    df['TotalCharges'], errors='coerce')
```

- `pd.to_numeric()` converts the column into a numeric data type.
- `df['TotalCharges']` is the column being converted.
- `errors='coerce'` converts invalid values into `NaN` instead of generating an error.
- The converted values are stored back in the same column.

**Example:**

- `'606'` becomes `606`.
- `'1440'` becomes `1440`.
- Blank or invalid values become `NaN`.

## **Step 7: Remove duplicate records**

```
df = df.drop_duplicates()
```

- `drop_duplicates()` removes duplicate rows from the dataset.
- It checks all columns by default.
- `df =` stores the resulting dataset back in `df`.

Here, the duplicate customer record with CustomerID `104` is removed because both rows contain identical values.

## **Step 8: Fill missing numerical values with median**

**Fill missing Tenure values**

```
df['Tenure'] = df['Tenure'].fillna(df['Tenure'].median())
```

- `df['Tenure']` selects the Tenure column.
- `.median()` calculates the middle value of the column.
- `.fillna()` replaces missing values with the calculated median.
- The cleaned values are stored back in the Tenure column.

**Fill missing MonthlyCharges values**

```
df['MonthlyCharges'] = df['MonthlyCharges'].fillna(    df['MonthlyCharges'].median())
```

- Selects the MonthlyCharges column.
- Calculates its median using `.median()`.
- Replaces missing values using `.fillna()`.

**Fill missing TotalCharges values**

```
df['TotalCharges'] = df['TotalCharges'].fillna(    df['TotalCharges'].median())
```

- Selects the TotalCharges column.
- Calculates the median of available numerical values.
- Replaces missing values with that median.

**Why median?**

Median is less affected by extremely high or low values compared with the mean. It is commonly used to fill missing numerical values.

## **Step 9: Fill missing categorical values with mode**

```
df['Gender'] = df['Gender'].fillna(df['Gender'].mode()[0])
```

- `df['Gender']` selects the Gender column.
- `.mode()` calculates the most frequently occurring value.
- `[0]` selects the first mode.
- `.fillna()` replaces missing values with that most frequent value.
- The cleaned values are stored back in the Gender column.

**Important:** Mode is commonly used to fill missing categorical values.

## **Step 10: Convert categorical columns into numerical values**

**Convert Gender**

```
df['Gender'] = df['Gender'].map({'Male': 1, 'Female': 0})
```

- `.map()` replaces categorical values with numerical values.
- `Male` is converted into `1`.
- `Female` is converted into `0`.
- This makes the Gender column numerical.

**Convert Churn**

```
df['Churn'] = df['Churn'].map({'Yes': 1, 'No': 0})
```

- Converts the Churn column into numerical values.
- `Yes` becomes `1`.
- `No` becomes `0`.

This process is called **Label Encoding**.

## **Step 11: Display cleaned dataset**

```
print("\nCleaned Dataset:")print(df)
```

- Displays the heading.
- Prints the final cleaned DataFrame.
- Shows the dataset after removing duplicates, handling missing values and converting categorical columns.

## **Step 12: Check missing values after cleaning**

```
print("\nMissing Values After Cleaning:")print(df.isnull().sum())
```

- `isnull()` checks for missing values.
- `sum()` counts missing values in each column.
- This verifies whether the cleaning process successfully handled the missing values.

Expected result: All columns should show `0` missing values for this sample dataset.

## **Step 13: Display final dataset information**

```
print("\nFinal Dataset Information:")print(df.info())
```

- Displays the final dataset heading.
- `df.info()` shows the updated number of rows, columns, non-null values and data types.
- It helps verify that the preprocessing operations were applied.

**Exam note:** Write `df.info()` directly instead of `print(df.info())` to avoid the extra `None` in the output.
